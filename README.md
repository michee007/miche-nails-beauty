# Miche Nails & Beauty - Calculadora de Precios

Calculadora interactiva y profesional diseñada para **Miche Nails & Beauty**. Permite a los clientes cotizar sus servicios de manicure, pedicure, sistemas (Polygel, Soft Gel, Acrílico) y decoraciones en tiempo real con una interfaz moderna y elegante.

## ✨ Características

- **Cotización en Tiempo Real**: Visualización instantánea del costo total según las selecciones.
- **Sistemas Personalizables**: Selección de largo (Cortas, Medianas, Largas) con precios diferenciados.
- **Diseño y Decoración**: Opciones detalladas para niveles de diseño y decoraciones por uña.
- **Resumen Detallado**: Generación de un resumen claro para la cliente.
- **Compartir**: Función para copiar el resumen y enviarlo por WhatsApp.
- **Impresión/PDF**: Opción para generar un comprobante físico o digital.
- **Diseño Premium**: Interfaz estética con paleta de colores nude y oro, optimizada para móviles.

## 🚀 Tecnologías

- **HTML5**: Estructura semántica.
- **CSS3**: Diseño responsivo y animaciones fluidas (Vanilla CSS).
- **JavaScript**: Lógica de cálculo y manipulación del DOM.
- **Lucide Icons**: Iconografía moderna y minimalista.
